# Courtyard by Marriott – 4D Construction Simulation

Interactive 4D simulation (3D model + programme + payment-delay scenarios) in a single HTML file.
Presented by Leela Rise Private Limited · built by Zenisth Studio.

- `index.html` – the live page (open in any browser, no install)
- `commercial-sample/index.html` – Zenisth-branded sample version
- `src/` – viewer source (Three.js); `python build.py` rebuilds the HTML
- `tools/` – IFC tessellation and schedule-mapping scripts (IfcOpenShell)

Hosting with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
